OOC Archive v1.2
작성일: 2026-08-17

[이번에 바뀐 것]
누구나 열람할 수 있고 글쓰기 비밀번호를 입력하면 추가, 수정, 삭제할 수 있는 공개 OOC 아카이브를 만들었습니다.
우측 상단 열쇠 버튼에서 한 번 잠금 해제하면 해당 기기에서 비밀번호가 자동 적용됩니다.
[바뀌지 않은 것]
참고 사이트의 흰색 미니멀 카드형 분위기와 단순한 사용 흐름을 유지했습니다.

1. 사이트에서 할 수 있는 일

누구나 OOC 목록을 보고 검색하고 복사할 수 있습니다.
글쓰기 비밀번호를 아는 사람은 Add OOC 버튼으로 새 글을 등록할 수 있습니다.
등록된 카드의 Edit와 × 버튼으로 수정하거나 삭제할 수 있습니다.
PC와 휴대폰에서 같은 목록이 보입니다.

우측 상단 열쇠 버튼을 누르고 글쓰기 비밀번호를 입력하면 잠금 해제 상태가 유지됩니다.
잠금 해제된 상태에서 열쇠 버튼을 다시 누르면 저장된 비밀번호가 지워지고 잠깁니다.

2. 안전한 저장 구조

GitHub Pages는 공개 화면을 담당합니다.
온라인 공용 저장 서버는 글 목록과 글쓰기 비밀번호 검사를 담당합니다.
글쓰기 비밀번호는 공개되는 사이트 파일에 적지 않습니다.

3. 사용 준비

온라인 저장 서버와 GitHub Pages 배포 설정은 제작자가 완료합니다.
사이트 주소와 글쓰기 비밀번호를 전달받으면 바로 사용할 수 있습니다.

4. 정상 작동 확인

사이트 첫 화면에 OOC Archive와 Add OOC 버튼이 보이면 화면은 정상입니다.
처음에는 열쇠 버튼을 눌러 비밀번호를 입력하거나 Add OOC에서 직접 비밀번호를 입력합니다.
열쇠로 잠금 해제한 뒤에는 Add OOC에서 제목, 분류, 내용만 입력하면 됩니다.
저장 후 새 카드가 보이고 다른 기기에서도 같은 카드가 보이면 전체 연결이 정상입니다.
틀린 비밀번호를 입력했을 때 “글쓰기 비밀번호가 맞지 않습니다.”가 나오면 비밀번호 보호도 정상입니다.

5. 주의

글쓰기 비밀번호는 config.js, app.js, GitHub 저장소에 절대 적지 마세요.
공용 PC에서는 사용 후 열쇠 버튼을 다시 눌러 반드시 잠가 주세요.
삭제는 즉시 반영되므로 필요한 글은 삭제 전에 내용을 복사해 두세요.
